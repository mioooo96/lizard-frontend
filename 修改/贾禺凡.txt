（1）无限滚动的实现
<div class="product-container" @scroll="handleScroll">
通过 @scroll="handleScroll" 监听容器的滚动事件。

const handleScroll = (e: Event) => {
  const container = e.target as HTMLElement
  const { scrollTop, scrollHeight, clientHeight } = container
  if (scrollHeight - (scrollTop + clientHeight) < 50) {
    loadMore()
  }
}
scrollTop：滚动条距离容器顶部的高度。
scrollHeight：容器内容的总高度（包括不可见部分）。
clientHeight：容器的可见高度（即容器本身的高度）。
scrollHeight - (scrollTop + clientHeight)：表示容器底部距离当前滚动位置的剩余高度。
< 50：当剩余高度小于 50 像素时，认为用户接近底部，触发 loadMore() 方法加载更多数据。
